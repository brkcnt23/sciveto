🤖 Layer 5: KUL AI (Proprietary, Closed-Loop) [NEW]
Architecture
Proprietary — NOT GPT-4o, NOT Claude API. Independent model trained on manufacturing data.
Deployment
Hybrid: Cloud (SaaS shared model) + On-Premise (local fine-tuning with factory's own data)
Data Privacy
Zero Cloud Transmission in on-premise mode. Factory data stays within network. No external API calls.
Core Capabilities
• Demand forecasting per category & time window
• Supplier evaluation (cost, delivery, quality)
• Project cost estimation & quote generation
• Production scheduling & resource optimization
• Risk detection (delays, bottlenecks, overruns)
• Performance KPIs (worker, equipment, waste)
• Anomaly detection (unusual patterns)
• Custom fine-tuning on factory data

🗂️ Data Model (Dynamic Schema Binding)
Categories
User-created (e.g. "Membran", "Çelik Halat", "Bant Saflama")
Fields (Per Category)
User-defined (marka, metraj, kalite, ağırlık, raf, batch, serial...)
Prisma Binding
Auto-generates PostgreSQL tables from user schema. No manual migrations.
Inventory States
Stok • Reserved • Used • Waste • Released
Warehouse Tracking
Barcode/RFID • Location/Rack • In/Out timestamp • Weight • Batch/Serial • QC status
Audit Trail
Every transaction logged (user, timestamp, action, before/after)
☁️ Deployment Models
Cloud SaaS Mode
Hosted on Sciveto servers • Shared KUL model • Standard encryption • Regular backups • Multi-tenant
On-Premise Mode (Self-Hosted)
Zero cloud dependency • Local KUL fine-tuning with factory data • No data sent externally • Full control • Premium option
Hybrid Option
Cloud API + local KUL instance • Best of both worlds • Factory data privacy + cloud benefits
